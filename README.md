Flip It 🎮 — Emoji Memory Game
A simple and accessible memory game where you match emotions with their emojis. 
How to Play

Click Start Game to begin
Flip two cards by clicking or pressing Enter/Space
Match the emotion word (e.g. "Happy") with its emoji (😄)
Find all 6 pairs to win!

Features

6 unique emotion/emoji pairs (12 cards total)
Move counter and pair tracker
Cards shuffle on every new round
Win message when all pairs are matched
Keyboard accessible — fully playable without a mouse

Accessibility

All cards are reachable via Tab key
Enter or Space flips a focused card
Screen reader labels on all cards
Labels update to "Matched!" when a pair is found
aria-live regions announce move and pair counts

Built With

HTML5 (semantic elements: header, main, section, footer)
CSS3 (Grid layout, 3D card flip with transform and perspective)
Vanilla JavaScript (DOM manipulation, event handling, game logic)
